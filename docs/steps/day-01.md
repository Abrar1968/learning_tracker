## 📦 Step 1: Laravel 12 Installation (30 min)

### 1.1 Create New Laravel 12 Project

```bash
# Navigate to projects directory
cd f:/projects

# Create Laravel 12 project
composer create-project laravel/laravel learning_tracker

# Navigate into project
cd learning_tracker

# Verify Laravel 12
php artisan --version
# Output: Laravel Framework 12.x.x
```

### 1.2 Initial Configuration

```bash
# Copy environment file (if not exists)
cp .env.example .env

# Generate application key
php artisan key:generate

# Set permissions (if on Linux/Mac)
chmod -R 775 storage bootstrap/cache
```

### 1.3 Configure `.env` File

Edit `.env`:

```env
APP_NAME="Learning Progress Tracker"
APP_ENV=local
APP_KEY=base64:...  # Generated by artisan key:generate
APP_DEBUG=true
APP_URL=http://localhost:8000
APP_TIMEZONE=UTC

LOG_CHANNEL=stack
LOG_LEVEL=debug

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=learning_tracker
DB_USERNAME=root
DB_PASSWORD=your_password_here

BROADCAST_DRIVER=log
CACHE_DRIVER=file
FILESYSTEM_DISK=local
QUEUE_CONNECTION=sync
SESSION_DRIVER=file
SESSION_LIFETIME=120
```

### 1.4 Test Installation

```bash
# Start development server
php artisan serve

# Open browser: http://localhost:8000
# You should see Laravel welcome page
```

### 3.3 Customize User Model (Laravel 12 Features)

**Update `app/Models/User.php`**:

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;

class User extends Authenticatable
{
    use HasFactory, Notifiable;

    /**
     * The attributes that are mass assignable.
     */
    protected $fillable = [
        'name',
        'email',
        'password',
    ];

    /**
     * The attributes that should be hidden.
     */
    protected $hidden = [
        'password',
        'remember_token',
    ];

    /**
     * Get the attributes that should be cast.
     * 
     * @return array<string, string>
     */
    protected function casts(): array
    {
        return [
            'email_verified_at' => 'datetime',
            'password' => 'hashed',
        ];
    }
}
```

## ⚡ Step 5: Alpine.js Integration (30 min)

### 5.1 Install Alpine.js

```bash
npm install alpinejs
```

### 5.2 Configure Alpine in `resources/js/app.js`

Update `resources/js/app.js`:

```javascript
import './bootstrap';
import Alpine from 'alpinejs';

// Make Alpine available globally
window.Alpine = Alpine;

// Alpine.js plugins can be registered here
// Example: Alpine.plugin(customPlugin);

// Start Alpine
Alpine.start();

// Log Alpine version for debugging
console.log('Alpine.js loaded:', Alpine.version);
```

## 🆘 Troubleshooting

### Common Issues

**Issue**: `composer install` is slow
```bash
# Solution: Use packagist mirror
composer config -g repo.packagist composer https://packagist.org
```

**Issue**: Vite not compiling
```bash
# Solution: Clear cache and reinstall
rm -rf node_modules package-lock.json
npm install
npm run dev
```

**Issue**: Database connection failed
```bash
# Solution: Verify credentials
php artisan tinker
DB::connection()->getPdo();

# Check .env file matches your MySQL settings
```

**Issue**: Permission denied (Linux/Mac)
```bash
# Solution: Fix permissions
sudo chmod -R 775 storage bootstrap/cache
sudo chown -R $USER:www-data storage bootstrap/cache
```

**Issue**: Alpine.js not working
- Check browser console for errors
- Verify `npm run dev` is running
- Clear browser cache
- Check `resources/js/app.js` imports Alpine correctly
